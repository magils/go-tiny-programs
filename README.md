# Go Tiny Programs

Collection of short programs for learning and practicing Go syntax and language features.


### How to use this repo

Use this repo as a reference on how to use and implement Go languauge and features.


### How to run the code

1 - Open your terminal.
2- `cd` to the repo folder.
3 - Execute this command with the program name you want to execute: `go run <program-name>.go`
